## Governed LV standard

Start LV delivery with the published standard, without choosing a layout.
Discover `report.export` and its LV standard job through `report.tasks`.
One declarative JSON job pins the exact roster, saved versions, held context,
project parties, contract, logos/digests and issue identity. It produces
independent A0/A3 transformer sheets and separate combined collections.
Each collection opens with front matter on its own paper (A0 for the A0 set,
A3 for the A3 set): cover, key map with every drawing reference, sheet index,
legend, general notes and revisions.
PNG previews precede each PDF; inspect them before delivery.
Dense schedules continue on numbered sheets, included in standalone PDFs,
combined PDFs and the index; every source row remains accounted for.

The focused circuit alone owns labels and schedules. Neighbouring circuits
remain muted context. Existing/new pens differ physically in colour and
monochrome. Missing optional context is a bounded omission, never a lost sheet.
The mandatory attribution has no override. Versioned, kernel-validated JSON
can change issue/title-block fields or named transformer furniture; it never
renames source identities or alters neighbours. Discover the template registry
and override schema through `report.layout.schema`. Keep the manifest and
repeatability hashes. A local standard export publishes nothing.

The request carries revision-pinned API printing documents and exact style
resolver receipts for every entity/source/paper role. Pens, label typography,
context emphasis, paper/map-scale scaling and table typography come from those
documents. Never author or seed them from this print workflow. The Styles API
owns resolution and default seeding; an absent tuple or stale revision refuses
by name. Colour/monochrome uses the API-captured ink variant. Preserve the
baseline/branch raster diff table and thumbnails beside the repeatability proof.
For A4 identity, printing_document carries the governed HTML/status layout and
its revision/digest; rendering changes no saved engineering verdict.

Report language belongs to the project's existing Network Template. Use its served
report locale and discover the live task's catalogue refusals. English and French
ship; additional locales use complete catalogue data. A missing setting requires
a reviewed dry-run-first backfill. Kernel filenames are authoritative; migrate
stored spelling mismatches instead of adding an alternate lookup.
